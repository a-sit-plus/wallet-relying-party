# Terminal Service Provider

This service implements the SP of the "Wallet Terminal SP Use Case".

Users can log in to this service with ID Austria, either directly in the browser, or with their Wallet App over OIDC SIOPv2.

See <https://github.com/a-sit-plus/compose-wallet-app/> for the Compose Wallet App.
